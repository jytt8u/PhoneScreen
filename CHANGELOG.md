# Changelog

## 1.0.0 — 2026-10-04

- Android screen, mouse and keyboard input, and phone audio on Windows over Wi-Fi.
- Russian interface with pairing, connection, quality presets and audio options.
- Portable release containing the verified scrcpy 4.1 runtime.
- Automatic installation from the official release, progress display, cached archive reuse and manual ZIP installation.
- TLS enforcement in the active connection, loopback-only transport and ADB server, embedded runtime hashes and file locks.
- Parallel device capability checks and low-latency transport settings.
- 66 local checks with the real runtime, plus a successful live download/install check.
